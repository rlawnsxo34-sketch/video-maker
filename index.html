📲 포이무비 홈 화면 앱 설치

아래 버튼을 누르거나 브라우저 우측 상단 [⋮] ➔ [홈 화면에 추가 / 앱 설치]를 눌러 설치하세요.

1 갤럭시 (안드로이드) 스마트폰에서 앱으로 추가하기

크롬(Chrome)이나 삼성 인터넷으로 접속한 뒤, 우측 상단(또는 하단) 메뉴 [⋮] 버튼 터치 ➔ [홈 화면에 추가] 또는 [앱 설치]를 누르면 바탕화면에 귀여운 '포이무비' 앱 아이콘이 생깁니다.

2 아이폰 / 아이패드 (Safari)에서 앱으로 추가하기

Safari 브라우저로 접속한 뒤, 하단 중앙의 [공유하기(네모 위 화살표 ⬆️)] 버튼 터치 ➔ 메뉴를 내려 [홈 화면에 추가]를 누르면 아이폰 홈 화면에 '포이무비' 앱이 설치됩니다.

3 PC (크롬 / 엣지 브라우저)에서 앱으로 설치하기

브라우저 주소창 오른쪽 끝의 [모니터+다운로드 아이콘]을 클릭하거나, 우측 상단 메뉴 [⋮] ➔ [전송, 저장, 공유] ➔ [페이지를 앱으로 설치]를 누르면 PC 바탕화면과 작업표시줄에 독립된 프로그램처럼 실행됩니다.
